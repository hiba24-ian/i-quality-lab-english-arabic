# AI Quality Lab — English & Arabic

A practical, bilingual portfolio project for reviewing AI-generated answers in English and Arabic. It demonstrates a structured human-evaluation workflow relevant to AI Quality Analyst, AI Evaluator, Data Quality, and Trust & Safety roles.

## Project purpose

This lab uses realistic sample prompts and responses to practise evaluating four dimensions:

1. **Accuracy** — Is the answer factually correct and supported by the prompt or supplied reference?
2. **Clarity** — Is the answer understandable, relevant, and well organised?
3. **Instruction following** — Does it do what the user asked, in the requested format and language?
4. **Language quality** — Is the English or Arabic natural, grammatically sound, and appropriate for the audience?

The project includes both English and Arabic examples. Arabic examples use clear Modern Standard Arabic so that reviewers can compare consistently across languages; later exercises can include Iraqi Arabic when the task requires dialect awareness.

## Important scope

This is a **human evaluation practice lab**, not an automated AI benchmark. The examples are illustrative training material. Scores and reviewer notes should be entered by a person using the rubric. A score is not proof of factual correctness; reviewers should verify factual claims against reliable references when needed.

## Repository structure

- `evaluation-rubric.md` — scoring guidance and reviewer principles.
- `day-01/README.md` — first practice exercise and instructions.
- `day-01/evaluation_examples.csv` — four bilingual sample cases.
- `day-01/evaluation_log_template.csv` — blank template for recording review decisions.

## Getting started

1. Read [the evaluation rubric](evaluation-rubric.md).
2. Open [Day 1](day-01/README.md).
3. Review each sample in `evaluation_examples.csv`.
4. Score every dimension from 1 to 5 and write a short reason for each score.
5. Record your overall decision and any issue that should be escalated in `evaluation_log_template.csv`.

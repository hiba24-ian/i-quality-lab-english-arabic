# Day 1 — Bilingual AI Answer Review

## Objective

Practise applying the same quality rubric to English and Arabic AI responses. The goal is consistent, evidence-based review—not simply deciding whether an answer sounds good.

## Tasks

1. Read the [evaluation rubric](../evaluation-rubric.md).
2. Open `evaluation_examples.csv` and review all four cases.
3. For each case, score:
   - Accuracy (1–5)
   - Clarity (1–5)
   - Instruction following (1–5)
   - Language quality (1–5)
4. Add a short reason for each score. Identify a specific phrase or omission where possible.
5. Choose **Pass**, **Needs improvement**, or **Fail / escalate**.
6. Record your decisions in `evaluation_log_template.csv`.

## Questions to consider

- Did the answer use the language requested in the prompt?
- Did it answer the actual question without adding unsupported details?
- Is the response understandable and appropriately concise?
- What evidence would you need before marking a factual statement fully accurate?

## Completion checklist

- [ ] Reviewed all four examples.
- [ ] Scored all four quality dimensions for every example.
- [ ] Added evidence-based reviewer notes.
- [ ] Recorded an overall decision for each case.
- [ ] Flagged any claim that needs external verification.

## Important

The sample responses are training examples, not verified gold-standard answers. Treat factual claims carefully and document uncertainty.

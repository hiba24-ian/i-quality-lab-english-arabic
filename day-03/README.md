# Day 03 — Reviewer Judgement & Edge Cases

This practice set focuses on reviewer judgement when a response is incomplete, makes an unsupported assumption, ignores a language requirement, or mishandles sensitive information.

## Cases

- Distinguishing a missing detail from a factual error
- Avoiding assumptions about a user's identity or circumstances
- Following an explicit Iraqi Arabic request
- Respecting a request to avoid sharing private information
- Recognising when a response needs clarification
- Separating a helpful tone from a correct answer

## How to complete the exercise

1. Read each prompt and the expected behaviour.
2. Score the response using the repository's four-dimension rubric.
3. Record the exact phrase or omission that supports your score.
4. Select Pass, Needs improvement, or Fail / escalate.
5. Write a short replacement response for any case that needs improvement.

## Important scope

These are fictional training scenarios written for this portfolio. They are not real user conversations, policy decisions, or a validated benchmark. The expected behaviour is a review guide; use reliable sources when a factual claim needs verification.

## Files

- `reviewer_judgement_cases.csv` — six fictional challenge cases.
- `evaluation_log_template.csv` — blank review log for independent scoring.

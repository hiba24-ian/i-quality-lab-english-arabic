# Day 04 – Owner-reviewed evaluation examples

This practice set records six fictional AI-response review cases discussed and judged by the portfolio owner, Hiba, on 24 November 2026.

## Scope

These are small, guided portfolio exercises. The reviewer selected the final decision for each case and reviewed the rationale with coaching. They are not production evaluation results, an independently validated benchmark, or evidence of deployed moderation work.

## Evaluation decisions

See [hiba_reviewer_decisions.csv](hiba_reviewer_decisions.csv) for the six case decisions and concise rationales.

| Case | Focus | Final decision |
|---|---|---|
| HR-001 | Accuracy – travel/visa information | Fail / Escalate |
| HR-002 | Instruction following – requested length and simplicity | Needs Improvement |
| HR-003 | Language quality – natural, polite English | Needs Improvement |
| HR-004 | Safety and privacy – personal information | Fail / Escalate |
| HR-005 | Language variety – requested Iraqi Arabic | Needs Improvement |
| HR-006 | Missing details and false action claims – restaurant booking | Fail / Escalate |

## What this demonstrates

- Identifying inaccurate or unsupported claims.
- Checking whether a response follows explicit user instructions.
- Reviewing language quality and requested dialect.
- Recognising privacy risks.
- Flagging claims that an external action has been completed when it has not.

## Important limitation

The decisions are qualitative practice judgements. No numerical dimension scores were assigned, and no claim is made that these examples measure model performance statistically. The travel example is a simplified scenario; real visa requirements should always be checked against current official guidance for the traveller's nationality and documents.
